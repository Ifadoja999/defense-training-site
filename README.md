# Incendiary Training Services — Web Platform

Client-facing web application for a B2B safety training company.

## What it does

- Public-facing site for scheduling and program inquiries
- Course catalog and booking integration
- Admin tooling for managing training engagements and client accounts

## Tech stack

- **Framework:** Next.js (App Router)
- **Backend:** Supabase (PostgreSQL + Auth)
- **Deployment:** Vercel
- **Styling:** Tailwind CSS
